# EventSpotter / Агрегатор предстоящих событий

EventSpotter - агрегатор предстоящих событий по всей России

## 📌 О проекте
Платформа, которая собирает и показывает все предстоящие мероприятия
в городах России: концерты, фестивали, клубные вечеринки, джем-сейшны из нескольких источников:  
Яндекс.Афиша, Ticketland, Kassir.ru, Ponominalu, TimePad

## 🎯 Проблема
- Музыкальные события разбросаны по разным площадкам
- Нет удобного поиска с фильтрами
- Легко пропустить концерт любимого артиста

## 💡 Решение
Агрегация всех мероприятий с последующим умным поиском и рекомендациями.

## 🛠 Технологический стэк
✅ fastapi -> Веб-фреймворк  
✅ pydantic -> Валидация данных  
✅ alembic -> Миграции БД  
✅ redis -> Кэширование  
✅ sqlalchemy -> ORM  
✅ postgresql -> основное хранилище
